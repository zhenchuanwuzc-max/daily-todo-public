# 每日待办 1.2.0 · 项目跟进正式版

事情跟进与项目跟进现在进入同一个正式版本。两个 Tab 共用事项，项目、里程碑、负责人、截止日期和完成状态保持一致。

- 事项支持行内编辑、多人负责人、紧凑日期选择、近三天筛选与手动排序。
- 项目支持里程碑、右键新增事项、任务模板、预计上线时间、资料链接和删除恢复；全部完成的项目自动收起，撤销完成后恢复。
- 人员工号、项目群和周报接收群可维护；本版只保存配置，不发送钉钉消息或周报。
- 项目数据使用文件锁与按字段合并，保留双方新增、独立字段修改和撤销完成。
- App 内置后台服务及同步组件；首次正式启动迁移已有本机配置，之后不再依赖旧源码目录运行服务。

## 安装与升级

Intel 和 Apple Silicon 下载同一个 `daily-todo-1.2.0-macos-universal.zip`，附 `SHA256SUMS.txt`。安装包不包含个人待办、人员名单或私有数据仓库。

**原正式版 1.0.22：** 公开发布后，可用「检查更新 → 立即更新」获取本版。旧更新器只取第一个 ZIP，因此本版仅发布一个双架构通用包。旧更新器没有本版新增的 App 回滚事务；需要保留旧 App 备份时，推荐使用下面的手动安装命令。

**项目预览版 1.1.4：** 原预览版没有启用正式版自动更新，需要手动安装这一次。准备本版源码和已登录的 GitHub CLI，在源码目录运行：

```bash
scripts/release.sh --install 1.2.0
```

命令适用于已经安装 `~/Applications/每日待办.app` 且已有私有数据目录的 Mac。它下载唯一通用包、验证 SHA-256 与签名，备份旧 App，再执行可回滚安装；健康检查通过才报告成功。已有源码目录请保留未提交改动，不要直接覆盖。进入 1.2.0 正式版后，后续可使用应用内更新。

首次启动会显示准备进度，核验已有服务与数据目录，备份启动配置、同步脚本和数据快照，再将后台服务切换到已安装 App。迁移不改写现有 `todos.json`，不修改私有仓库远端。发现陌生进程、未完成的 Git 操作或配置不一致时会停止并提示，避免替换错误服务。

App 安装备份保存在 `~/Library/Application Support/daily-todo/update-backups/`；服务迁移备份位于同目录下的 `runtime-backups/`。更新失败会尝试恢复旧 App、服务配置与同步脚本；不会用旧快照覆盖更新期间的新事项。不要让新旧写入端同时编辑项目数据；其他 Mac 也需升级后再参与编辑。

## 发布与验证边界

CI 在 arm64、x86_64 两种机器运行完整测试，各自打包后合并每个原生二进制，校验源码、编译模块、版本与签名，再在两种机器上解压同一个 ZIP，以隔离数据启动包内服务。流程先生成草稿，本机安装验收与真实数据目录健康检查通过后才公开并设为 latest。

本机测试和 CI 不代表其他 Mac 已完成实际双向同步或交互验收。包使用临时签名，未做 Developer ID 公证；没有 Instruments 帧时间测量，不声明性能改善。详细功能与同步约定见 [项目使用说明](PROJECT_TRACKING.md) 和 [同步部署说明](../sync/DEPLOY.md)。

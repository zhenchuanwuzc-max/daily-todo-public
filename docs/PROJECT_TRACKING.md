# 事情跟进与项目跟进

同一应用两个 Tab，共用同一条事项。事情跟进保持一行一件事，点击名称、负责人、截止日期即可修改；归属项目和里程碑可选。

## 使用

- 新建普通事项必填内容、负责人、截止日期；负责人默认 Ocean。截止日期不决定何时开始显示，未来截止的事项也立即进入清单。
- 添加区默认显示事项、负责人、截止日期；优先级、分类、项目归属在「更多」中调整，收起保留已选值。
- 事项行不再显示计划日按钮，也不再单列未来事项。存量 `due` 原值保留，但不影响普通事项进入事情清单或拖动排序；`deadline` 继续独立用于截止提醒。
- 顶部「重复任务」直接管理每日、每周、每月的模板，可添加和删除；删除模板保留已生成的事项。模板按原周期生成，新增后立即检查当日是否应生成，添加失败保留输入。
- 项目页可新建、编辑、删除和恢复项目；里程碑可新增多个、编辑、调整顺序、删除和恢复。
- 项目页的现有事项始终支持行内编辑：名称、负责人、截止日期、优先级和完成状态均直接操作。右上角「新增事项 / 收起新增」只控制各里程碑的新增框，默认收起，切换时保留尚未提交的草稿。
- 项目事项通过行首手柄拖动上下排序，也支持手柄上的上下方向键；只在当前里程碑或待安排内换行，可跨优先级，不改变项目、里程碑、负责人或日期。项目顺序单独保存，不影响事情跟进的优先级内排序；保存失败回退原顺序。
- 项目内的事项已属于当前项目，行内不再显示项目归属下拉；需要调整归属时在「事情跟进」中操作。
- 从里程碑下添加事项时，截止日期默认使用里程碑目标日期，可手动修改；成功添加后，下一条继续默认该日期。里程碑没有日期则留空，仍需填写。修改里程碑日期不会改写已有事项或正在输入的草稿。
- 项目里的负责人默认 Ocean，可直接输入任意姓名，也可点击旁边的下拉箭头从共用人员名单选择；下拉显示完整名单，不受当前输入值限制。新增事项输入框加高，事项行统一字号和对齐。
- 左侧直接列出进行中的项目，不显示搜索与状态筛选；列表下方「＋ 新增项目」用于创建项目，空列表时也可用。右上角「项目设置」提供添加里程碑与当前项目操作。
- 项目名称以紧凑小标题显示，和项目设置一起吸顶，长列表滚动时仍能确认当前项目。
- 右键左侧项目条目或右侧项目标题，打开「编辑 / 删除」菜单；左键项目条目用于切换项目，点击项目标题直接编辑。键盘聚焦后可用 Shift+F10 打开菜单、方向键选择、Escape 关闭；点击里程碑标题始终可编辑。项目设置不再重复提供编辑和手动归档。
- 项目至少有一条有效事项、全部事项完成且每个有效里程碑都完成时，自动从进行中列表和核心摘要收起；空里程碑不算完成。自动收起按共享事项实时计算，不回写项目归档字段。通过「项目设置 → 已完成项目 → 查看」打开历史，撤销完成或新增未完成事项即恢复到进行中。存量手动归档、删除的项目继续通过「项目设置 → 恢复项目」恢复；恢复后仍满足完成条件的项目进入已完成项目。
- 里程碑内容直接展开，不提供折叠按钮。顶部「显示已完成」默认关闭，隐藏已完成事项及全部事项完成的里程碑，空里程碑仍显示；开启后可查看历史、撤销完成，选择保存在当前浏览器中。进度和当前节点仍按全部有效事项计算。
- 点击里程碑名称编辑，弹窗内可上下移动和删除。调整顺序会立即保存，表单中的名称、负责人和目标日期需点击保存后生效。
- 「项目设置 → 里程碑排序」集中列出全部未删除里程碑（包含已完成），通过上移、下移调整并自动保存；顺序同步影响当前节点和下一步。
- 删除项目只隐藏项目，事项仍在事情清单；删除里程碑后事项显示在该项目的待安排。恢复后原关系仍在，期间手动调整的归属不回退。
- 至少一条事项且全部完成时，里程碑自动完成；撤销或新增未完成事项后恢复进行中。历史完成事项计入进度，空里程碑不算完成。
- 存量事项没有负责人时显示 Ocean，没有截止日期时显示未设截止；打开页面不会批量回写。循环任务不关联项目。
- 核心项目摘要显示当前节点、完成数、下一步和逾期事项。日期按北京时间计算，无后台推送。

## 跟进配置

- 新建或编辑项目时可填「钉钉群号」，每个项目分别保存；可留空或清空。
- 页面右上角「设置 → 人员维护」集中维护全应用共用的姓名与工号，两个 Tab 和所有项目均使用同一份人员名单；自动列出各处使用的负责人，也可独立添加人员。工号以文本保存，保留前导零；同名共用一份配置，重名同事应使用带部门等区别的显示名。存量负责人与事项不会因此被改写。
- 页面右上角「设置 → 周报接收群」配置独立于项目群的接收名单，一行一个群号；支持多个、去重和清空。没有进行中的项目时这两项全局设置仍然可用。
- 当前只保存配置，不查询或验证企业身份、不创建钉钉待办、不发送群消息，也不启动周报定时发送。群号和工号的真实身份需在后续发送前核验。
- 修改工号会校验打开表单时的旧值，遇到他处已更正的工号提示冲突并保留输入。周报群按增删差异保存，不覆盖另一设备新增的接收群。

## 本地预览

在分支 checkout 中运行 `python3 scripts/preview.py`，访问 `http://127.0.0.1:8797/`。
数据副本放在 `~/Library/Application Support/daily-todo-preview/data/`，不会同步到真实数据仓库。
界面显示「隔离预览 · 数据副本」。正式应用继续使用 `~/daily-todo-data/todos.json`。

## 验证与打包

```bash
python3 -m unittest discover -s tests -q
python3 tests/browser_projects.py
TODO_TEST_BROWSER=webkit python3 tests/browser_projects.py
python3 tests/browser_followup_config.py
TODO_TEST_BROWSER=webkit python3 tests/browser_followup_config.py
python3 tests/browser_project_completion.py
TODO_TEST_BROWSER=webkit python3 tests/browser_project_completion.py
python3 tests/browser_project_reorder.py
TODO_TEST_BROWSER=webkit python3 tests/browser_project_reorder.py
python3 tests/browser_reorder.py
python3 tests/browser_recurring.py
TODO_TEST_BROWSER=webkit python3 tests/browser_recurring.py
~/daily-todo/venv/bin/python setup.py py2app
python3 scripts/install-local.py
```

最后一行只检查并展示安装位置。验证后用 `python3 scripts/install-local.py --install` 安装本机：备份旧应用、真实数据和启动配置，更新应用与私有同步脚本，校验服务后打开应用。安装不发布公开 Release。

备份位于 `~/Library/Application Support/daily-todo/deploy-backups/<时间>/`。
安装失败会恢复旧应用、同步脚本和启动配置；不会自动覆盖可能刚被用户修改的真实数据。手动回退时先停止两个版本的写入，保留当前数据副本，再恢复备份应用和配置；旧版不能与新版并行写项目数据。

## 同步与兼容

后端按事项保存，跨进程文件锁与本地 Git 合并共享；联网过程不持有数据写锁。
合并按 ID 和字段处理，保留双侧新增、独立字段修改和撤销完成。具体部署文件见 [sync/DEPLOY.md](../sync/DEPLOY.md)。
其余 Mac 必须升级同一版本及同步脚本再编辑新版数据。本地模拟双设备测试不等于另一台真实 Mac 已完成升级或验收。
外部调用 `POST /todos/add` 新增普通事项时须提供 `deadline`（YYYY-MM-DD），`owner` 缺省为 Ocean；缺少日期返回明确错误，不自动猜日期。已有读取、PATCH 和循环任务端点继续可用。

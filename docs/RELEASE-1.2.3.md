# 每日待办 1.2.3 · 保留跨天待办

- 事情跟进默认显示逾期待办，以及今天和接下来两天到期的待办。
- 每日、每周、每月的重复任务按原计划生成。跨天后，尚未完成的事项继续留在待办里。没有单独截止日期的重复任务会显示原定日期。
- 之前被旧版本自动跳过的历史记录需要单独恢复。

1.2.2 在合成双架构安装包时发现两台构建机的证书文件不一致，未发布。1.2.3 的两种架构使用同一份 CA 证书。

使用正式版的 Mac 可通过「每日待办 → 检查更新」升级。使用项目预览版的 Mac 需要手动安装，步骤见 [正式版安装说明](RELEASE-1.2.1.md#安装与升级)，安装时使用版本号 1.2.3。
